# QuizMaster – Online Quiz Application

QuizMaster is a web-based MCQ quiz application developed using Java and Spring Boot.

## Features
- Professional Dark Purple User Interface
- Multiple Choice Questions (MCQs)
- Correct and Incorrect Answer Feedback
- Score Calculation
- Final Result Display
- Restart Quiz Functionality
- REST API for Question Management and Answer Checking

## Technologies Used
- Java 21
- Spring Boot
- Spring Web
- Maven
- HTML
- CSS
- JavaScript

## Project Structure
- `src/main/java` – Java backend code
- `controller` – Quiz REST API controller
- `src/main/resources/static` – Frontend files
- `pom.xml` – Maven dependencies and configuration

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

`.\mvnw.cmd spring-boot:run`

5. Open your browser and visit:

`http://localhost:8080`
